# Data Refinery v1.11.1 릴리즈 노트

Data Refinery v1.11.1은 데이터 파이프라인의 안전성, 작업 실패 시의 단계적 정리 처리, 그리고 키보드 접근성을 중점적으로 개선한 품질 안정화 패치 릴리즈입니다.

## 주요 변경 사항

### 1. CSV 구조 복구 및 데이터 안전성
- **열 개수 초과 불량 행 사전 차단**: 원본 데이터 처리 중 기대 열 수를 초과하는 잘못된 형식의 행을 감지하면 명확한 행 번호 안내와 함께 처리를 중단하고, 불완전하거나 손상된 출력 파일이 생성되지 않도록 보호합니다.

### 2. 프로모션 템플릿 검증 및 발행 실패 정리
- **중복 헤더 보호**: `Promotion_Master` 및 `Support_Rules` 시트 내 중복된 비어있지 않은 열 헤더가 존재할 경우 사전 검증을 통해 차단합니다.
- **작업 결과 유지**: 탭 간 이동 시에도 이전에 검증되거나 처리된 프로모션 결과가 초기화되지 않고 유지됩니다.
- **발행 실패 시 보상 정리(Compensating Cleanup)**: 임시 파일 단계적 쓰기(staged writes)를 시도하며, 이후 발행 단계에서 오류가 감지되면 이미 발행된 출력물을 삭제하는 보상 정리를 수행합니다(이는 모든 파일에 걸친 장애 원자적 트랜잭션이 아니며, 기존에 존재하던 파일의 복원을 보장하지는 않습니다).

### 3. 데이터 집계(Aggregator) 입력 검증 및 실패 처리
- **사전 열 수 검증**: 집계 엔진 구동 전 원본 CSV 행의 열 초과 여부를 사전 검사하여 잘못된 데이터 집계를 방지합니다.
- **샘플 미리보기 표기 명확화**: 집계 미리보기가 전체 데이터가 아닌 표본 샘플 기준임을 사용자가 직관적으로 인지할 수 있도록 안내합니다.
- **취소 및 저장 실패 시 임시 파일 정리 시도**: 일반적인 취소 및 저장 실패 경로에서 임시 파일 정리를 시도하여 잔여 파일을 최소화합니다(단, 삭제 작업 자체가 실패하는 경우까지 완전한 제거를 보장하지는 않습니다).

### 4. 필드 리스트 키보드 접근성 개선
- **시각적 포커스 링**: 데이터 집계 필드 목록(`FieldListView`)에 키보드 포커스 이동 시 명확한 액센트 링이 표시됩니다.
- **자동 행 초기화**: 목록으로 포커스 진입 시 플레이스홀더(힌트)가 아닌 첫 번째 유효 항목을 자동으로 선택·포커스합니다.
- **연속 키보드 작업 지원**: Return(배치) 및 Delete(제거) 키를 사용해 마우스 없이 필드를 연속적으로 조작할 수 있으며, 행 이동 및 삭제 후 목록이 재렌더링되어도 선택 상태와 포커스 위치를 안정적으로 보존합니다.

### 5. 테스트 및 CI 검증
- CSV 처리, 프로모션 정규화, 데이터 집계, 키보드 탐색 및 실패 처리 경로 전반에 걸쳐 총 440개의 자동화 테스트(Automated tests, UI/통합 테스트 포함)가 로컬 환경에서 통과되었습니다.
- CI 선택 린트 검사(`ruff check --select E4,E7,E9,F src tests`)를 통과하며, Windows CI는 린트 및 테스트, 서명되지 않은 테스트 인스톨러/런처 빌드, 임시 러너에서의 무인(silent) 설치/제거 스모크 테스트를 실행합니다(정식 릴리즈 서명 또는 체크섬 검증이 아닙니다).

## 품질 및 수동 데스크톱 QA 안내 (참고사항)

- 본 릴리즈는 자동화된 위젯 테스트 및 코어 파이프라인 검증을 통과한 **품질 고도화 패치**입니다.
- 단, 패키징 및 설치된 실제 Windows 데스크톱 앱 환경에서의 전체 키보드 전용 워크플로, 고DPI 디스플레이 배율(125%/150%), 3개 국어(한국어, 영어, 폴란드어) UI 레이아웃의 실환경 전수 검증은 현재 **수동 데스크톱 QA 대기(Pending/Unverified)** 상태입니다.
- 본 릴리즈는 상용 제품 정식 출시가 아니며, 데스크톱 앱의 데이터 안전성과 사용성 강화를 위한 업데이트입니다.
