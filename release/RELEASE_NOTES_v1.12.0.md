# Data Refinery v1.12.0 릴리즈 노트

v1.12.0은 기간별 원본 CSV를 누적·검수하고, 승인한 결과를 팀 공유 폴더에 게시해 Excel에서 새로고침할 수 있도록 데이터셋 배포 기능을 추가합니다.

## 주요 변경 사항

### 데이터셋 누적 및 배포
- 데이터셋별 입력 폴더와 공유 배포 폴더, 기간 열, 수치 열, 중복 확인 키를 설정합니다.
- 새 기간은 추가하고 수정된 기간은 교체합니다. 재실행 시 중복 누적을 막고, 입력 파일이 이전 기간을 포함하지 않는 경우 누락을 방지하기 위해 교체를 차단합니다.
- 배포 전에 기간, 행 수, 금액 합계, 오류와 주의사항을 검수하고 승인합니다.
- 공유 폴더의 `current` CSV, 버전별 스냅샷, `manifest.json`을 게시합니다. 파일 시스템 전체의 장애 원자성은 보장하지 않습니다.

### Excel 연결
- Microsoft 365 Excel의 Power Query와 데이터 모델을 사용하는 매크로 없는 분석 템플릿을 생성합니다.
- 제작 PC에 Excel 자동화가 불가능하면 Power Query 연결 안내가 포함된 수동 템플릿을 만듭니다.
- 분석 사용자는 앱, Python, DuckDB, ODBC를 설치하지 않고 공유 폴더 읽기 권한과 Excel 기본 기능으로 새로고침할 수 있습니다.
- Excel COM 기반 개인 폴더 복사 후 새 데이터 새로고침 검증은 `DATAREFINERY_EXCEL_TESTS=1`로 선택 실행합니다.

### 품질 및 검증
- 전체 자동 테스트와 Ruff 검사를 통과하도록 수정했습니다.
- GUI 글꼴/DPI, 회사 공유 드라이브의 다중 사용자 갱신, 실제 사용자 권한 정책은 대상 운영 환경에서 별도 확인이 필요합니다.
