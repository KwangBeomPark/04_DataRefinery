# Data Refinery v1.13.0 릴리즈 노트

v1.13.0은 동유럽(체코어, 폴란드어 등) 데이터 환경에서의 인코딩 호환성을 대폭 개선하고, 데이터 집계 중 인코딩 불일치가 발생할 경우 자동으로 감지하여 원클릭으로 안전하게 재실행할 수 있는 정밀 인코딩 복구(Self-Healing) 시스템을 도입합니다.

## 주요 변경 사항

### 다국어/동유럽 인코딩 지원 강화
- **중앙/동유럽 인코딩 지원**: `CP1250` (Windows Central European), `ISO-8859-2` (Latin-2), `CP852` (DOS Central European)를 인코딩 감지 후보군에 기본 포함하였습니다.
- **멀티 리전 샘플링 엔진**: 상위 1MB가 순수 ASCII(영문/숫자)로 구성되어 있더라도 파일 중간 구간(33%, 66%)을 추가 샘플링하여, 대용량 파일 후반부에 위치한 체코어/폴란드어 특수 문자(예: `0xa8` 트레마/디에레시스, `Ę` 오고네크 등)를 사전에 정확히 탐지합니다.
- **정밀 인코딩 스캔 (`detect_encoding_precise`)**: 인코딩 불일치 발생 시 파일 청크를 전수 스캔하여 미정의 문자 점수를 계산하고 가장 왜곡이 없는 최적의 코드페이지를 자동 선별합니다.

### 수동 인코딩 선택 및 투명성 제어
- **상단 인코딩 콤보박스 추가**: 데이터 집계기(Aggregator) 상단 설정 영역에 인코딩 드롭다운을 추가하여 현재 감지된 인코딩을 한눈에 확인할 수 있습니다.
- **다국어 코드페이지 직접 선택**: 필요에 따라 `자동 감지`, `UTF-8`, `Windows-1250 (체코/폴란드)`, `CP949 (한국어)`, `Windows-1252 (서유럽)`, `ISO-8859-2`를 명시적으로 선택하여 작업할 수 있습니다.

### 원클릭 대화형 정밀 복구 (Self-Healing UX)
- **친절한 원인 안내 팝업**: 집계 도중 인코딩 오류(`UnicodeDecodeError` / `AggregationEncodingError`) 발생 시 난해한 에러 코드 대신 동유럽 문자 포함 안내와 함께 추천 인코딩(예: `CP1250`)으로 재실행할지 묻는 대화상자를 표시합니다.
- **설정 유지 원클릭 재시도**: 대화상자에서 '예'를 클릭하면 기존 설정값(그룹 키, 수치 열, 비율식 등)을 그대로 유지한 채 `errors='replace'` 보호막과 추천 인코딩이 적용된 정밀 모드로 즉시 자동 재실행됩니다.
- **다국어 지원**: 한국어, 영어뿐만 아니라 폴란드어(Polski) UI 환경에서도 완벽하게 현지화된 안내를 제공합니다.

### 품질 및 안정성 검증
- 체코어/폴란드어 `0xa8` 바이트를 포함하는 6종의 복원력 단위 테스트(`test_encoding_resilience.py`)를 추가하고 전체 집계기 테스트를 100% 통과하였습니다.
