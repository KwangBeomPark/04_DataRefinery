# 데이터셋 배포 사용 방법

4번째 탭에서 정리된 CSV를 기간별로 누적하고, 검수한 결과를 회사 팀 공유 폴더에 배포합니다. 자료를 만드는 담당자는 이 앱을 사용하고, 분석하는 사람은 Microsoft 365 Excel 64비트의 기본 기능만 사용합니다.

## 앱 설치와 데이터 저장 위치

앱은 `%LOCALAPPDATA%\Programs\Data Refinery`에 설치됩니다. 이 폴더는 프로그램 파일용입니다.
설정·로그는 `%LOCALAPPDATA%\Programs\Data Refinery\UserSetting`, 데이터셋 설정·작업 DB는
`%LOCALAPPDATA%\Programs\Data Refinery\UserSetting\datasets`에 저장합니다. 공유 배포 폴더에는 승인된 CSV와
분석용 Excel 파일을 둡니다. 저장 위치들은 용도가 다르며, 소스·빌드 폴더 정리 시
사용자 데이터를 삭제하거나 공유 폴더 연결을 변경하지 않습니다. 기존 로컬 설정·작업 DB는
최초 실행 시 새 UserSetting으로 복사·검증하며 원본은 백업으로 보존합니다.

## 처음 설정하기

1. **데이터셋 배포 → + 새 데이터셋**을 선택합니다.
2. 이름, 정리된 CSV의 입력 폴더, 공유 배포 폴더를 지정합니다. 거래선 손익·TV 상세·냉장고 상세마다 별도의 배포 폴더를 사용합니다.
3. 기간 열 이름, 합계를 확인할 수치 열, 중복을 확인할 식별 키 열을 입력합니다. 열 이름은 CSV 헤더와 같아야 합니다.
4. 기간은 `2026-04` 또는 `202604`처럼 월을 식별할 수 있어야 합니다. UTF-8 CSV를 권장하며, 기존 한국어 파일은 고급 옵션에서 CP949/EUC-KR을 지정할 수 있습니다.
5. 동일 월에 여러 파일을 합칠지, 충돌로 차단할지 선택하고 저장합니다.

## 매월 작업하기

1. 왼쪽에서 데이터셋을 선택하고 **새 자료 확인**을 누릅니다.
2. 추가할 월과 교체할 월을 확인한 뒤 **누적 · 검수 실행**을 누릅니다.
3. 반영 전후의 기간·행 수·수치 합계와 오류·주의사항을 확인합니다.
4. 결과가 맞으면 **결과 확인 및 검수 승인**을 누릅니다.
5. **공유 폴더에 배포하기**를 누릅니다. 누적 실행만으로 배포되지는 않습니다.

새 월은 추가하고 수정된 월은 교체합니다. 같은 자료를 다시 실행해도 중복 누적하지 않습니다. 입력에서 이전 월 파일을 보관 폴더로 옮겨도 누적한 과거 기간은 유지합니다. 수정하는 월에 기여한 일부 파일이 빠져 있으면 자료 누락을 방지하기 위해 교체를 차단합니다. 연간/3개년 보관이나 자동 삭제 정책은 아직 적용하지 않습니다.

배포 폴더의 `current`에 최신 CSV, `versions`에 버전별 CSV, `manifest.json`에 배포 정보가 저장됩니다. 일반적인 쓰기 오류에는 이전 공개 파일을 복원하도록 처리합니다. CSV와 메타데이터는 여러 파일이므로 파일시스템 전체의 단일 트랜잭션이나 정전·연결 단절에서의 완전한 복구를 보장하는 방식은 아닙니다. 실제 회사 공유 드라이브에서 파일 잠금과 갱신 동작을 확인한 뒤 운영하세요.

## Excel 파일 제공하기

1. 배포 후 **Excel 분석 템플릿 생성**을 누릅니다. 제작자 PC에는 데스크톱 Excel이 있어야 합니다.
2. 생성한 매크로 없는 `.xlsx`에는 공유 CSV 연결, 데이터 모델, 기간별 기본 피벗이 들어갑니다. 수치 열이 있으면 합계가 기본 값으로 배치됩니다.
3. 다른 사람에게 이 Excel 파일을 제공합니다. 각자는 개인 폴더에 저장하고 **데이터 → 모두 새로 고침**으로 최신 자료를 읽습니다.
4. 피벗의 행·열·필터를 자유롭게 바꾸고 자신의 분석 파일을 저장하면 됩니다. 다른 사람에게 앱·Python·DuckDB·ODBC 설치를 요구하지 않습니다.

모든 사람이 같은 공유 경로에 접근할 수 있어야 합니다. 사용자마다 드라이브 문자가 다르면 공통으로 접근할 수 있는 경로를 지정하세요. 회사 정책에 따른 외부 연결 허용과 공유 폴더 읽기 권한은 필요할 수 있습니다.

데이터셋 표시 이름을 바꿔도 배포 파일 이름은 유지합니다. 공유 폴더 자체를 옮기면 기존 Excel의 연결 경로를 다시 설정해야 합니다.

제작자 PC에서 Excel을 사용할 수 없으면 연결 안내 문서를 생성합니다. 이 안내 문서는 연결된 분석 템플릿과 다릅니다. 담당자가 Excel에서 연결을 완성한 파일을 제공해야 분석 사용자는 새로고침만으로 사용할 수 있습니다.

## 검증 범위

기간 추가·교체, 입력 아카이브 후 누적 보존, 중복 방지, 잘못된 숫자·기간 차단, 실패 시 공개본 복원, 실제 작업 실행기를 통한 UI 작업을 자동 테스트합니다. 실제 Excel에서도 템플릿을 개인 폴더로 복사하고 새 월을 추가한 뒤 새로고침하여 데이터 모델과 피벗에 반영되는 것을 확인했습니다.

화면의 글꼴·DPI·작은 창 사용성과 실제 회사 공유 드라이브의 여러 사용자 동시 접근은 운영 환경에서 확인할 항목입니다. 새 탭의 업무 화면 문구는 현재 한국어 중심입니다.
