## 판정

Gemini 전달본과 실제 Git 변경을 비교해 코드 결함과 잘못된 검수 기록을 수정했습니다. 확인한 코드·모의 검증 범위는 통과했으며, **새 운영 릴리즈의 서명·실제 설치·게시까지 완료한 상태는 아닙니다.** 변경은 커밋하지 않은 작업 트리에 남아 있습니다. 다국어 README·인포그래픽은 이번 범위에서 제외했습니다.

직접 업로드 계약은 설치 파일 하나(03은 PPAM), 매니페스트 JSON 하나, 체크섬 TXT 하나입니다. 기존 버전별 메타데이터 이름을 유지합니다. GitHub 자동 Source code ZIP/TAR와 매니페스트 내부 앱 기록은 추가 업로드 자산으로 세지 않습니다.

## 다음 작업과 보존 기준

1. 변경을 검토·커밋하고 새 배포가 필요한 프로젝트만 새 버전·릴리즈 노트를 준비합니다. 이미 배포한 파일을 재서명·덮어쓰기하지 않습니다.
2. 새 바이너리는 사용자의 관리자 SimplySign 세션에서 빌드·서명·실물 검증합니다. 인증서 표시나 fixture 통과만으로 완료 처리하지 않습니다.
3. 격리 Windows에서 실행 중 구버전 종료·거부·잠금, 업그레이드·취소·실패·UserSetting 보존·제거를 검증합니다. 04 ssDone/SHA 코드 확인은 실제 설치 합격을 대신하지 않습니다.
4. 합격한 새 버전 Draft의 세 자산을 검증한 뒤 게시합니다. 03·07은 수동 게시 절차가 남아 있습니다. 이번에는 운영 서명·설치·push·태그 생성·게시를 실행하지 않았습니다.

기존 설정·업무 자료·서명 파일·공개 자산·태그를 보존했습니다. 03의 Gemini 생성 untracked v1.4.0 PPAM/JSON/TXT 세 파일도 보존했으며 새 검증 완료본으로 취급하지 않습니다. 03은 실제 Office 암호 서명 검증, 원본 commit/버전 증명, TLS 신뢰 문제 해결이 남아 있습니다. TLS 검증을 끄지 않았습니다.
