# Data Refinery 데스크톱 수동 QA 체크리스트

본 체크리스트는 Data Refinery Windows 데스크톱 앱의 품질 고도화를 위한 수동 검증 항목을 정리한 문서입니다. 2026-09-27 Windows 소스 앱 워크스루에서 확인된 사실을 기준선으로 삼고, 아직 검증되지 않은 실환경 항목을 체계적으로 점검하기 위해 작성되었습니다.

> **주의:** 본 문서는 상용 출시를 보장하거나 품질 완료를 선언하는 문서가 아닙니다. 코드를 모르는 사용자가 핵심 작업 3가지(CSV 구조 복구, 프로모션 템플릿 정규화, 데이터 집계)를 안전하게 마칠 수 있는지 확인하기 위한 실무 검증용입니다.

- [x] **자동 테스트 및 CI**: 로컬 전체 테스트 스위트 387개 및 ruff 통과, main 커밋 `572d998` 기준 Windows release-check CI 성공.
- [x] **CSV 구조 복구**: 기본 샘플 파일 처리 시 3개 행 정상 저장 확인.
- [x] **프로모션 템플릿 정규화**: 입력된 프로모션 템플릿 처리 시 일별 5개 행(daily rows) 정상 산출 확인.
- [x] **프로모션 빈 템플릿 거부**: 빈 템플릿 입력 시 2개 조치 가능 이슈(actionable issues) 안내 및 저장 버튼 비활성화 확인.
- [x] **데이터 집계**: 샘플 미리보기 4개 그룹 확인, 전체 저장 시 4개 그룹 정상 저장 확인. 샘플 미리보기 매출(약 1.32억)과 저장 매출(약 31억) 차이 확인 및 '샘플 전용(sample-only)' 레이블 표기 검증.
- [x] **상태 보존 및 탐색기 연동**: 탭 전환 후에도 프로모션 결과 유지 및 '결과 폴더 열기' 실행 시 일별 파일 자동 선택 확인.
- [x] **키보드 접근성 기본**: `Tab` + `Space` 조작으로 작업 탭 전환 가능 및 시각적 포커스 링(visible focus ring) 표시 확인.
- [x] **단일 머신 성능 관찰 (순수 실행 및 계측 맥락 명시, 목표치 아님)**:
  - **순수 실행(Uninstrumented) 저장 시간**:
    - `monthly_ledger_sample.csv` (~3.66 MB): 3회 저장 소요 시간 0.135s / 0.164s / 0.121s (4개 행 출력). (이전 0.563s는 tracemalloc 오버헤드)
    - 대용량 임시 샘플 (102,477,881 바이트): `aggregate_dataset` 3회 저장 소요 시간 3.485s / 3.139s / 3.222s (4개 행 출력). (이전 17.435~22.738s는 tracemalloc 계측 오버헤드로 인한 런타임 왜곡)
  - **작업 단계별 응답성 (계측 환경 관찰값)**:
    - 스키마 로드: 3.66 MB 0.023s, 102 MB 0.024s.
    - 미리보기: 3.66 MB 0.034s, 102 MB 0.034s.
    - 그룹 수 계산: 102 MB 0.804s.
  - **Windows 프로세스 메모리 관찰 (102 MB 집계 시나리오)**:
    - Windows PSAPI `PROCESS_MEMORY_COUNTERS_EX` 측정: 프로세스 `PeakWorkingSetSize` 92.4 / 92.5 / 92.2 MB, 종료 시점 `PrivateUsage` 402.1 / 403.2 / 402.2 MB 관찰 (프로세스 import 포함, 단일 머신 관찰값이며 수용 목표 아님).

## 3. 수동 QA 체크리스트 (미검증 항목)

### 3.1 설치 앱 및 OS 환경 (Windows 10 / 11)
- [ ] **Windows 10 클린 환경**: `setup.exe` 인스톨러로 설치 후 시작 메뉴/바탕화면 바로가기 생성 및 정상 실행 확인.
- [ ] **Windows 11 클린 환경**: `setup.exe` 인스톨러로 설치 후 시작 메뉴/바탕화면 바로가기 생성 및 정상 실행 확인 (커밋 `af8a4e1`에서 Win11 10.0.26200 번들 구동 및 창 등록 PID 확인되었으나, 조작 도구 거부로 GUI 인터랙션 미검증; CI 무인 설치/제거는 통과했으나 `smoke_installer.ps1`은 GUI를 실행하지 않음).
- [ ] **설치 앱 내 3개 핵심 워크플로 완주**: 소스 실행이 아닌 실제 설치된 앱에서 CSV 복구, 프로모션 정규화, 데이터 집계 전체 과정 완주 확인 (현재 미검증, 소스 앱 워크플로는 이전 시점 증거로만 유효).
- [ ] **앱 제거(Uninstall) 검증**: 제어판/설정에서 정상 제거되고 잔여 파일 및 레지스트리가 올바르게 정리되는지 확인 (CI 임시 러너 무인 제거는 통과, 실환경 수동 점검 대기).

### 3.2 디스플레이 및 화면 배율 (DPI Scaling)
- [ ] **100% DPI 배율**: 표준 배율 환경에서 모든 탭의 컨트롤, 테이블, 버튼, 상태 문구 잘림 없음 확인.
- [ ] **125% DPI 배율**: 노트북/보조 모니터 흔한 배율에서 텍스트 줄바꿈 및 컨트롤 정렬 유지 확인.
- [ ] **150% DPI 배율**: 고배율 환경에서 폰트 오버플로우, 버튼 클릭 영역 겹침, 다이얼로그 잘림 없음 확인.
- [ ] **창 크기 조절**: 기본 창 크기, 최대화, 임의 크기 조절 시 반응형 레이아웃 깨짐 없음 확인.

### 3.3 전체 키보드 전용 작업 경로 (Full Keyboard-Only Journeys)
- [ ] **CSV 복구 완주**: 마우스 없이 `Tab`/방향키/`Enter`/`Space`로 파일 선택 → 자동 감지된 인코딩 확인 및 구분자/출력 형식 조정 → 복구 실행 → 저장 → 결과 열기 완주.
- [ ] **프로모션 정규화 완주**: 마우스 없이 템플릿 선택 → 검증 확인 → 일별 파일 저장 → 결과 열기 완주.
- [ ] **데이터 집계 완주**: 마우스 없이 파일 선택 → 그룹 열/값 열 선택 → 미리보기 실행 → 저장 완주.
- [ ] **대화상자 제어**: `Esc` 키로 모달/알림 닫기 및 기본 버튼 `Enter` 키 실행 동작 확인.

### 3.4 3개 국어 UI 레이아웃 (KO / EN / PL)
- [ ] **한국어(KO)**: 모든 탭 제목, 도움말 텍스트, 오류 안내, 다이얼로그 텍스트 자연스러움 및 잘림 없음.
- [ ] **영어(EN)**: 기본 UI 용어 일관성 및 라벨 줄바꿈 무결성 확인.
- [ ] **폴란드어(PL)**: 특수 문자(ą, ć, ę, ł, ń, ó, ś, ź, ż) 정상 렌더링 및 긴 단어로 인한 컨트롤 오버플로우 없음 확인.

### 3.5 모든 작업 흐름의 장애 복구 (Fault Recovery)
- [ ] **읽기 전용 저장 위치**: 결과 파일 저장 경로가 쓰기 금지된 경우 크래시 없이 명확한 오류 안내 및 원본 보존.
- [ ] **디스크 공간 부족**: 디스크 여유 공간이 부족한 상황에서 안전한 중단 및 임시 파일 정리.
- [ ] **데이터 집계 처리 취소**: 데이터 집계 대용량 파일 처리 도중 취소(Cancel) 버튼 클릭 시 UI가 안전하게 복구되고 부분/불완전한 출력 파일이 남지 않고 즉시 정리되는지 확인 (집계 취소 및 저장 실패 정리 회귀 테스트는 411개 테스트에 포함되어 통과했으나 실환경 수동 검증 미완료; CSV 복구 및 프로모션에는 작업 취소 버튼이 없으며, 취소 검증은 데이터 집계에 적용됨).
- [ ] **손상/변형 파일 입력 및 저장 실패**:
  - 열 개수 불일치 CSV 입력 시 행 번호 안내와 함께 안전한 거부.
  - 헤더보다 값이 많은 데이터 집계 CSV 입력 시 사전 차단 및 불완전 결과 방지.
  - 열 헤더가 중복된 프로모션 엑셀 템플릿 입력 시 덮어쓰기 방지 및 차단 안내.
  - 프로모션 배포 실패 시 롤백 및 데이터 집계 저장 실패 시 정리 안전성 확인.

### 3.6 대표 워크로드 벤치마크 및 메모리 체계 (Performance & Memory)
- [ ] **대표 워크로드 실측**: 단일 102 MB 집계 시나리오 외 다양한 대표 워크로드(소형 파일, 중형 파일, 복합 집계 등)에 대한 실환경 성능 측정.
- [ ] **재현 가능한 벤치마크 도구화**: 일회성 단일 머신 측정을 넘어 재현 가능하고 크로스 플랫폼 비교가 가능한 벤치마크 환경 구축 (벤치마크 스크립트에 격리된 TemporaryDirectory 및 결정론적 로컬 RNG가 적용되었으나 대표 워크로드 전반 실측은 미검증).
- [ ] **UI 반응성 유지**: 장시간 처리 중 UI 프리징("응답 없음") 방지 및 집계 취소 버튼 반응 확인.
- [ ] **반복 작업 후 메모리 누수 점검**: 연속해서 파일 처리 및 미리보기 수행 시 메모리가 누적 증가하지 않는지 확인.

### 3.7 외부 실사용자 검증 (5~10명)
- [ ] **대상 사용자 선정**: 코딩을 모르는 비개발자 사용자 5~10명 섭외.
- [ ] **도움 없는 샘플 작업 수행**: 별도 구두 설명 없이 앱 내 안내만으로 3개 샘플 작업 수행 관찰.
- [ ] **결과 및 마찰 지점 기록**: 혼란을 겪는 지점, 오류 발생률, 결과 도달 소요 시간 기록.
- [ ] **차단 요소 개선**: 관찰된 작업 방해 요인에 대한 우선순위별 UI/안내 개선 및 재검증.
