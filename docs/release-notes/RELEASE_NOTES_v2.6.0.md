# Data Refinery v2.6.0

외부 웹 브라우저 이탈 없이 프로그램 내부에서 최신 업데이트 파일을 자동으로 다운로드하고, 클릭 한 번으로 설치 마법사 실행 및 안전한 업그레이드까지 완료되는 **"인앱 원클릭 무중단 자율 업데이트 시스템"**을 전격 도입했습니다.

## 주요 변경 사항

### 1. 인앱 원클릭 자율 업데이트 다이얼로그 (`UpdateDialog`)
- **브라우저 이탈 없는 1-클릭 업그레이드**: 기존에 7단계(알림 ➔ 브라우저 이동 ➔ 깃허브 페이지 ➔ 파일 탐색 ➔ 다운로드 ➔ 앱 종료 ➔ 설치 파일 실행)로 진행되던 번거로운 여정을 단 1회의 클릭(`[⚡ 원클릭 업데이트]`)으로 완전히 단축했습니다.
- **버전 비교 및 마크다운 릴리즈 노트 프리뷰**: 새 버전 번호(v{latest})와 용량(MB), 상세 릴리즈 노트를 팝업 내부에서 마크다운 포맷으로 즉시 확인할 수 있습니다.
- **원클릭 자동 설치 기본 지원 (`chk_auto_install`)**: 다운로드 완료 즉시 인스톨러를 자동 실행하는 옵션이 기본 활성화되어 있어 불필요한 추가 조작을 없앴습니다.

### 2. 고성능 비동기 스트리밍 다운로더 & 원자적(Atomic) 교체
- **64KB 청크 단위 백그라운드 스트리밍**: $O(1)$ 메모리 점유 구조와 `QThread` 비동기 워커를 통해 대용량(100MB+) 설치 파일 다운로드 중에도 UI 프리징(멈춤)이 전혀 발생하지 않습니다.
- **실시간 다운로드 진행률 표출**: 다운로드된 용량과 총 용량, 퍼센트(`45.2 MB / 107.5 MB (42%)`)를 실시간 프로그레스 바로 피드백합니다.
- **원자적(.part) 임시 파일 교체**: 수신 중에는 `<파일>.exe.part`로 기록되며, 네트워크 조기 단절(`downloaded < total_size`) 발생 시 미완성 파일을 즉시 클린업하고, 정상 완료된 경우에만 원자적(`replace`)으로 최종 파일로 승격시킵니다.

### 3. Inno Setup 프로세스 핸드오버 및 무결성 보존
- **파일 락(UpgradeBlocked) 원천 차단**: 설치 프로그램 실행(`subprocess.Popen`) 직후 모달 다이얼로그 루프를 즉시 언블록(`self.accept()`)하고 Data Refinery를 정상 종료(`QApplication.quit()`)하여, 설치 파일 복사 단계에서 발생할 수 있는 윈도우 OS 핸들 락 충돌을 100% 방지했습니다.
- **사용자 데이터 및 설정 영구 보존**: `%LOCALAPPDATA%\Programs\Data Refinery\UserSetting` 및 DuckDB 작업 DB, Enterprise Suite Registry와의 완벽한 격리 호환성을 유지하여 업그레이드 후에도 모든 기존 설정과 작업 내역이 안전하게 보존됩니다.

### 4. 스마트 캐싱 및 다중 안전망
- **중복 다운로드 방지**: 동일 버전의 무결한 설치 파일이 이미 로컬에 존재할 경우 다운로드를 생략하고 즉시 `[🚀 지금 설치하기 (앱 자동 종료)]` 상태로 전환되어 네트워크 트래픽과 대기 시간을 아낍니다.
- **보조 탈출구 완비**: 특수 사내 보안망이나 프록시 환경을 고려하여 `[🌐 웹 브라우저로 열기]`, `[📂 다운로드 폴더 열기]`, `[다운로드 취소]` 기능을 완비했습니다.

### 5. 다국어 및 품질 무결성
- **3개국어(한국어, 영어, 폴란드어) 100% 동기화**: 21개 신규 업데이트 UI 키 전원 반영 및 영문/폴란드어 모드 잔존 한글 0건 정규식 검증 통과.
- **릴레이 4라운드 교차 검수 만장일치 PASS**: Codex Sol 6.1과 Claude Opus 5.5의 시스템 엔지니어링 및 엔터프라이즈 UX 심층 감사를 전원 승인으로 통과.
- **총 597개 단위/통합 테스트 전원 통과** (88.9s) 및 100만 행 벤치마크(1.96s) 무결점 통과.

## 배포 및 설치
- 설치 위치: `%LOCALAPPDATA%\Programs\Data Refinery`
- 사용자 설정·로그·데이터셋 DB: `%LOCALAPPDATA%\Programs\Data Refinery\UserSetting` (업데이트 시 안전 보존)
- 공식 배포 파일: `App04_DataRefinery_Setup_v2.6.0.exe`
