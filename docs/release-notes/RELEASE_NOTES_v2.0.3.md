# Data Refinery v2.0.3 준비

- 탭 순서를 데이터 집계·슬라이서 → 데이터셋 배포 → 프로모션 템플릿 → CSV 구조 복구로 변경했습니다. 시작 화면은 집계 탭입니다. Tkinter 호환 화면도 같은 순서를 사용합니다.
- 한국어·영어·폴란드어 전환 시 실제 업무와 탭 제목이 일치하며 선택한 업무와 입력 설정을 유지하도록 연결했습니다.
- 기존 집계·배포 탭의 UI·UX, 데이터 마트 제작을 위한 정제 기능과 새 탭의 필요성을 검토하고 단계별 개선 계획을 문서화합니다. 정제 탭과 후속 기능은 제안 단계입니다.
- 버전 단일 출처는 `src/version.py`이며 설치·설정·작업 DB·공유 배포 경로와 기존 서명 파일은 유지합니다.

이 문서는 소스 변경 기록입니다. 새 버전의 서명·설치 파일 빌드·실게시 완료를 의미하지 않습니다.
