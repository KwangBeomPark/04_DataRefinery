# Data Refinery v2.2.0

공식 신규 앱 아이콘(Fluent Glass Ribbon), UI 전체 다국어(한국어/영어/폴란드어) 100% 완전 현지화, 그리고 초보자도 한눈에 따를 수 있는 직관적인 `1 ➔ 2 ➔ 3` 단계 가이드 및 Progressive Step-Gating(단계별 조건 제어) 시스템을 도입합니다.

## 주요 변경 사항

### 1. 신규 공식 앱 아이콘 적용 (`Fluent Glass Ribbon`)
- 세련된 반투명 아크릴 리본 모티프의 단독 아이콘을 적용했습니다.
- 배경을 100% 투명(Transparent Alpha) 처리하고 캔버스 높이 96.5%를 꽉 채워 작은 크기(16x16, 32x32)에서도 선명하게 식별됩니다.
- 16x16부터 256x256까지 9개 해상도 레이어(32bpp RGBA)를 내장하여 Windows 작업표시줄, 시작 메뉴, 바탕화면에서 최적의 화질을 제공합니다.

### 2. UI 전체 다국어(ko / en / pl) 완전 현지화
- 언어를 영어(`en`) 또는 폴란드어(`pl`)로 전환 시 화면 전역에 단 하나의 한국어 문자(`[가-힣]`)도 남지 않도록 100% 현지화했습니다.
- `FilePickerWidget`, 스테퍼, 칩 에디터, 팝업 다이얼로그, 4개 탭 전역 및 모든 테이블 모델 헤더까지 실시간 언어 전환을 완벽 지원합니다.
- `i18n.py` 내 451개 번역 키를 3개 언어 간 1:1 완벽 동기화 및 전수 회귀 테스트를 구축했습니다.

### 3. 직관적인 `1 ➔ 2 ➔ 3` 단계 가이드 및 Progressive Step-Gating
- 처음 접하는 사용자도 망설임 없이 작업할 수 있도록 상단 가이드 배너 및 사전 조건 제어(Step-Gating)를 구현했습니다:
  - **CSV 복구 탭**: 1단계에서 원본 파일을 선택하기 전까지 2단계(읽기 옵션)와 3단계(저장 옵션 및 실행 버튼)를 안전하게 잠금 처리합니다.
  - **프로모션 템플릿 탭**: 엑셀 템플릿의 무결성 검증을 통과하기 전까지 결과 저장 섹션과 일별 지원금 생성 버튼을 비활성화합니다.
  - **데이터 집계 탭**: 원본 CSV를 선택하기 전에는 컬럼 탐색기 및 규칙 카드가 잠기며, `행 그룹(1개 이상)`과 `계산할 값(1개 이상)`을 모두 지정해야만 3단계 [미리보기] 및 [데이터 집계 및 저장하기] 버튼이 활성화됩니다.
  - **데이터셋 배포 탭**: 데이터셋을 선택해야 스캔/누적이 활성화되고, [★ 1단계: 기간 누적 및 검수]를 통과해야만 [✓ 2단계: 최종 배포] 버튼이 열려 데이터 오염 및 덮어쓰기 사고를 원천 방지합니다.

### 4. 코드 품질 및 안정성
- 전체 단위 테스트(577개) 및 1,000,000행 벤치마크 테스트 통과.
- 릴리즈 서명 파이프라인 및 사용자 설정/백업 안전성 검증 통과.
