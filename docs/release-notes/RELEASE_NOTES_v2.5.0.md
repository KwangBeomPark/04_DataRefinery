# Data Refinery v2.5.0

초보자 친화적 DWH 구축 실전 가이드(한국어·영어·폴란드어 3개국어), 대화형 가이드 다이얼로그, DuckDB 기반 마트 데이터 즉시 미리보기(실시간 검색 및 50/100/200행 동적 샘플링), 원천 데이터 시각 상태 뱃지 및 스마트 파일 임포터(덮어쓰기 보호 가드), Power Query M-Code 1초 직결 지원을 전격 도입했습니다.

## 주요 변경 사항

### 1. 초보자를 위한 DWH 구축 3개국어 실전 매뉴얼 및 대화형 가이드
- **3개국어 완벽 현지화 매뉴얼 탑재**:
  - `docs/DWH_BEGINNER_GUIDE_ko.md`: 한국어 실전 가이드 (5대 황금 수칙, 원천 규격, 엑셀 1초 직결법, 트러블슈팅)
  - `docs/DWH_BEGINNER_GUIDE_en.md`: 영어 실전 가이드
  - `docs/DWH_BEGINNER_GUIDE_pl.md`: 폴란드어 실전 가이드
- **대화형 온보딩 모달 (`DwhGuideDialog`)**: 1번 DWH 탭 상단의 `[📖 초보자 실전 매뉴얼]` 버튼을 클릭하면 4개 탭(5대 수칙, 파일 준비, 엑셀 연동, 문제 해결)으로 구성된 팝업이 현재 앱 언어에 맞춰 열리며, 하단의 전체 매뉴얼 열기 클릭 시 해당 언어의 공식 마크다운 문서를 OS 기본 뷰어로 즉시 실행합니다.

### 2. DuckDB 초고속 마트 데이터 즉시 미리보기 (`DwhPreviewDialog`)
- **엑셀 없이 즉시 확인**: DWH 파이프라인 빌드 완료 후 엑셀을 실행하지 않고도 화면 팝업에서 최종 손익 마트 데이터를 즉시 검증할 수 있습니다.
- **실시간 무지연 텍스트 필터**: 검색창에 고객명, 모델명, 기간 등을 입력하면 즉시 해당 행만 필터링되며 원클릭 지우기 버튼을 지원합니다.
- **수치 크기순 정렬**: 숫자 컬럼(매출, 원가, 마진, 이익 등) 클릭 시 텍스트 사전순이 아닌 실제 수치 크기(`float`) 순서로 정렬됩니다.
- **50 / 100 / 200행 동적 샘플링 및 상태 보존**: Codex Sol 6.1 기술 제언을 수렴하여 동적 행 제한 콤보박스를 탑재했으며, 행 수 변경 시에도 기존 검색 필터와 정렬 상태가 초기화되지 않고 유지됩니다. 조회 완료 즉시 DuckDB 커넥션을 닫아 OS 파일 핸들을 완전히 해제합니다.
- **원클릭 클립보드 복사**: `[📋 표 내용 복사 (TSV)]` 버튼으로 클립보드에 복사하여 엑셀에 바로 붙여넣을 수 있습니다.

### 3. 원천 데이터 준비 상태 비주얼 뱃지 & 스마트 파일 임포터
- **시각 상태 뱃지(Pill Badges)**: 카드 1의 원천 파일 3종에 대해 **에메랄드 그린(준비 완료)** / **앰버 오렌지(파일 누락)** 뱃지를 표시하여 파일 준비 여부를 한눈에 직관적으로 파악할 수 있습니다.
- **스마트 파일 임포터 (`[📂 가져오기]`)**: 복잡한 내부 폴더 경로를 몰라도 바탕화면이나 다운로드 폴더의 CSV를 선택하면 규격 폴더로 자동 복사 및 즉시 상태가 갱신됩니다.
- **덮어쓰기 방어 가드**: 기존 파일이 존재할 경우 `confirm_dialog`를 통해 덮어쓰기 여부를 재확인하여 실수로 인한 원본 데이터 유실을 원천 차단합니다.

### 4. 표준 엑셀 서식 자동 생성기 & 엑셀 1초 직결 (M-Code)
- **표준 엑셀 서식 다운로드**: `[📥 표준 엑셀 서식 다운로드]` 버튼을 누르면 고객 마스터, 제품 마스터, P&L 실적 3개 시트와 예시 데이터가 포함된 `DataRefinery_DWH_Template.xlsx`를 자동 생성하며, 저장 후 엑셀에서 바로 열어볼지 확인하는 원스톱 UX를 제공합니다.
- **Power Query M-Code 원클릭 복사**: `[⚡ Power Query M-코드 복사]` 버튼으로 엑셀 고급 편집기에 붙여넣기만 하면 1초 만에 DWH 로컬 파일과 직결되는 스크립트를 클립보드에 복사해 줍니다.
- **자가 치유(Self-Healing) 안내**: 외래키 무결성 위반(미매핑 마스터 코드) 발생 시 화면에 Top 5 누락 코드를 즉시 표시하고 `[📝 마스터 폴더 열기 (코드 추가)]` 버튼을 제공하여 즉각적인 치유를 유도합니다.

### 5. 아키텍처 및 품질 무결성
- **릴레이 교차 검증 통과**: Claude Opus 5.5(엔터프라이즈 UX 및 비즈니스 거버넌스)와 Codex Sol 6.1(시스템 아키텍트 및 릴리즈 엔지니어링)의 4라운드 교차 검수를 전원 만장일치 PASS로 통과.
- **전체 588개 단위/통합 테스트 전원 통과** (94.083s).
- **다국어 무결성**: 영어 및 폴란드어 모드에서 화면 전역 한글 잔존 0건 (`[가-힣]` 정규식 검증 완료).
