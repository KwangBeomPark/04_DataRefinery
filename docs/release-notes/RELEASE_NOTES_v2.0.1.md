# Data Refinery v2.0.1

대용량 자료를 정리하고 Excel 분석용 데이터셋을 만드는 네 가지 업무 화면을 PySide6(Qt)로 제공하며,
앱 설치와 사용자 설정 경로를 공통 규칙으로 정리했습니다. 이전 공개 버전 v1.12.0 이후의 화면·인코딩 개선도 함께 포함합니다.

- CSV 복구, 프로모션 정규화, 데이터 집계, 데이터셋 배포를 고해상도 Qt 화면에서 사용합니다. 기존 Tkinter 화면은 `--legacy-tk`로 실행할 수 있습니다.
- 데이터셋 등록 마법사에서 파일·키워드 선별, 표본 기반 열 역할 추천과 복합키 진단을 제공합니다.
- 앱은 `%LOCALAPPDATA%\Programs\Data Refinery`에 설치되고, 설정·최근 작업·프리셋·로그·작업 DB는 그 아래 `UserSetting`에 저장합니다.
- 기존 로컬 자료는 최초 실행 시 복사·검증합니다. 원본은 보존하며 새 위치의 기존 자료는 덮어쓰지 않습니다. 공유 CSV 경로와 Excel 연결은 유지됩니다.
- 업데이트·제거 시 UserSetting을 보존합니다. 공식 서명 빌드는 앱·런처·설치 파일·제거 프로그램에 서명과 타임스탬프를 적용하고 검증합니다.
- 동일 월 파일 처리 정책과 숫자 형식 선택이 실제 엔진에 저장되도록 수정했습니다. 지원하지 않는 식별 키별 병합·필수 열 누락 허용 선택지는 제거했습니다.
- 중앙유럽 인코딩 처리와 유럽식 숫자 처리를 개선하고, 레거시 인코딩 재시도 콜백 오류를 수정했습니다.
- 앱 버전 정의를 통일하고, 런처의 `Luncher` 오타를 `Launcher`로 수정했습니다. 중복 샘플·미사용 이미지를 정리하고 개발 규칙·코드맵을 공유합니다.

소비자는 Microsoft 365 Excel의 Power Query·데이터 모델·피벗 기능으로 공유 CSV를 읽습니다.
Python·DuckDB·ODBC 추가 설치가 필요하지 않습니다. 회사 공유 드라이브의 실제 권한·동시 접근은 운영 환경에서 확인하세요.

설치 파일: `App04_DataRefinery_Setup_v2.0.1.exe`.
서명된 배포 시 `SHA256SUMS.txt`와 `build-manifest.json`으로 파일 무결성·소스 커밋·서명 정보를 제공합니다.

검증: 코드 검사 통과, 회귀 테스트 528개 실행(527개 통과·선택 실행 Excel COM 1개 건너뜀).
