# Data Refinery v2.7.0

사용자가 막힘없이 직관적으로 작업할 수 있도록 돕는 **"Explain, don't block" 마이크로 넛지 인프라**, 초보자를 위한 **빈 상태 온보딩 안내 카드**, 그리고 실수로 인한 데이터 손실을 원천 차단하는 **원자적 파일 가져오기 및 트랜잭션 롤백 시스템**을 전격 도입했습니다.

## 주요 변경 사항

### 1. "Explain, don't block" 마이크로 넛지 시스템 (`src/qt/ui_state.py`)
- **차단 대신 명확한 이유와 행동 제시**: 버튼을 단순히 비활성화하여 사용자를 당황하게 만드는 대신, 비활성화된 이유(`⛔`)와 지금 바로 취할 수 있는 해결 행동(`💡`)을 툴팁과 스크린 리더 접근성 설명으로 친절히 안내합니다.
- **파이프라인 실행 중 실시간 잠금 동기화**: DWH 빌드가 백그라운드에서 실행되는 동안 관련 버튼 6종을 안전하게 잠그고, 언어 전환 시에도 실행 중 넛지 사유와 단계별 진행 체크마크(`✔`/`○`)가 실시간으로 동기화됩니다.

### 2. 초보자를 위한 빈 상태 온보딩 웰컴 카드 (Empty State Reassurance)
- **원본 불변 원칙 심리적 안심 제공**: 원천 파일이 아직 등록되지 않았을 때 `🔒 안심하세요: 원본 파일은 절대 변경되지 않습니다` 안내 카드를 상단에 배치하여 초보자의 심리적 장벽을 해소했습니다.
- **1-Click 샘플 데이터 자동 생성**: 테스트할 실데이터가 없어도 `[✨ 샘플 원천 데이터 자동 생성]` 버튼을 눌러 공식 마스터 2종과 100+ 계정 컬럼 P&L 실적 데이터를 단 1초 만에 즉시 합성 생성할 수 있습니다.

### 3. 무손실 원자적(Atomic) 파일 가져오기 및 트랜잭션 롤백
- **원천 폴더 내부 파일 재선택 시 소멸 방지**: 사용자가 이미 `pnl/` 폴더 안에 있는 CSV 파일을 다시 가져오기로 선택하더라도, 기존 파일 백업 전에 임시 스테이징(`.tmp`) 파일로 사본을 먼저 안전하게 확보한 뒤 원자적으로 교체(`replace`)하여 파일 소멸 위험을 원천 차단했습니다.
- **Windows 파일 잠금(`PermissionError`) 시 자동 롤백**: 사용자가 원천 CSV를 Excel 등에서 열어두어 파일 잠금이 발생하면, 백업 루프에서 이동했던 파일들을 즉시 역순으로 원위치 복원(롤백)하고 Excel 파일을 닫도록 친절한 안내 다이얼로그를 표시합니다.
- **타임스탬프 충돌 방지 고유 백업 헬퍼**: 동일 초 내에 연속 백업이 발생하더라도 `_1`, `_2` 시퀀스를 자동으로 부여하여 기존 백업본을 덮어쓰지 않습니다.

### 4. 독립 패키징 아키텍처 정비 (`src/sample_data.py`)
- **PyInstaller 동결(frozen) 빌드 완벽 호환**: 샘플 데이터 생성 핵심 로직을 루트 `scripts/` 폴더에서 `src/sample_data.py`로 격리 모듈화하여, 설치본 번들에서도 `ModuleNotFoundError` 없이 완벽히 동작하도록 구조를 정비했습니다. `scripts/generate_sample_data.py`는 CLI thin 래퍼로 경량화되었습니다.

### 5. 다국어 100% 동기화 및 릴레이 교차 감사 만장일치 PASS
- **3개국어(한국어, 영어, 폴란드어) 완전 지원**: 신규 넛지, 온보딩, 파일 잠금 안내 문구 전수 반영 및 영문/폴란드어 모드 잔존 한글 0건 정규식 검증 통과.
- **OpenAI Codex Sol 6.1 & Claude Opus 5.5 최종 PASS 승인**: 4차례에 걸친 엄격한 심층 릴레이 감사 지적 사항(P1~P3, R1, R2) 전면 해결 및 최종 승인 획득.
- **총 619개 단위/통합 테스트 전원 통과** (신규 넛지 전용 22개 테스트 포함) 및 100만 행 벤치마크(2.06초) 무결점 통과.
