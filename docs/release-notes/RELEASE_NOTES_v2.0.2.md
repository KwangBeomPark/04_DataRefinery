# Data Refinery v2.0.2 준비

- 새 설치 파일을 `App04_DataRefinery_Setup_v2.0.2.exe` 한 개로 제공하도록 빌드·서명·검증 계약을 통일했습니다. 이미 게시한 버전의 파일과 태그는 유지합니다.
- 런처는 새 이름과 과거 `-Setup` 이름을 인식하고 공식 URL·버전·서명자 검증을 유지합니다.
- 설정·프리셋·최근 작업의 원자적 저장과 손상 자료 보존을 보강하고 UserSetting 전체 백업/검증/별도 복원 경로를 제공합니다. 설정만 백업할 때 제외되는 작업 DB와 외부 CSV/Excel은 별도 확인합니다.
- 실행 중 앱 정상 종료 및 잠금 차단을 유지하고 설치 전 `_internal` 전체 삭제를 제거했습니다. 확인된 구형 실행 파일은 설치 성공 후에만 정리합니다.

서명·실제 설치/업그레이드/제거·게시 검수는 별도 릴리스 게이트입니다. 이 준비 문서 자체는 서명 또는 게시 완료의 증거가 아닙니다. DLL 잔여 파일과 설치 중 실패/취소의 실제 복구도 격리 Windows에서 확인해야 합니다.
