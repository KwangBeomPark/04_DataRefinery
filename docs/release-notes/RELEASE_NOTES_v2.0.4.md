# Data Refinery v2.0.4

v2.0.2 이후의 집계 안전성·화면 개선과 Windows 검증 절차 보강을 포함합니다.

## 작업 흐름과 집계

- 탭을 데이터 집계·슬라이서 → 데이터셋 배포 → 프로모션 템플릿 → CSV 구조 복구 순서로 배치했습니다. Qt와 Tkinter 호환 화면에 같은 순서를 적용합니다.
- 한국어·영어·폴란드어를 전환할 때 선택한 업무와 입력 설정을 유지합니다. 작은 집계 창에서는 스크롤로 설정과 실행 버튼에 접근할 수 있습니다.
- 집계 출력이 원본과 같은 실제 파일이면 차단합니다. 상대 경로·대소문자 차이·파일 별칭도 확인하며, Qt에서 기존 결과 교체를 확인받습니다. 작업 도중 생긴 미승인 결과도 덮어쓰지 않습니다.
- 숫자 표기를 `1,234.56` 또는 `1.234,56 / 1 234,56`으로 선택하고 프리셋에 저장합니다. 표기 설정이 없는 예전 프리셋은 현재 화면 선택을 유지합니다.
- 선택한 표기에 맞지 않는 수치, 문자 `N/A`·`nan`, 무한대와 수치 범위 초과는 기본적으로 미리보기·저장을 중단합니다. 오류 열·건수·예시를 안내하고 이전 파일을 보존합니다. 수식에만 쓰는 원본 열에도 같은 검사를 적용합니다.
- 빈칸·`-`·실제 결측은 별도 집계합니다. 합계에서는 0으로 처리하고 count/mean/min/max에서는 제외합니다.

## Windows 검사와 배포 안정성

- 개발 PC·일반 빌드·GitHub Actions가 같은 품질 검사를 사용합니다. 활성화된 pre-push 훅은 검사 실패 시 원격 푸시를 차단합니다.
- 체크아웃과 임시 폴더가 서로 다른 드라이브에 있는 Windows 환경을 회귀 검사합니다.
- 일반 Excel 파일 생성 검사는 실제 Office 실행과 분리하고, 실제 Excel 연결·데이터 모델·피벗·새로고침은 명시적으로 실행하는 통합 검사로 유지합니다. COM 연결 오류가 성공으로 숨겨지지 않는지도 검사합니다.
- Git Bash에서 Windows PowerShell로 전달되던 호환되지 않는 모듈 경로를 분리합니다. 외부 명령의 실패와 의도적 실패 주입의 종료 코드도 구분합니다.

## 설치와 사용 안내

- 설치 위치는 `%LOCALAPPDATA%\Programs\Data Refinery`, 설정·로그·작업 DB는 그 안의 `UserSetting`입니다. 공유 CSV와 기존 사용자 자료의 위치는 유지합니다.
- 공개 배포 파일은 `App04_DataRefinery_Setup_v2.0.4.exe`, `build-manifest.json`, `SHA256SUMS.txt` 세 개입니다. 기존 공개 버전의 태그와 자산은 보존합니다.
- 소비자는 추가 드라이버 설치 없이 Excel 기본 Power Query로 공유 배포 CSV를 읽습니다.
- 숫자 표기는 원본에 맞게 선택해야 합니다. 두 표기에서 모두 가능한 `1.234` / `1,234`는 자동 판별하지 않습니다. 미지원 회계 표기와 float64 계산의 한계는 유지됩니다. 표본 검사 통과는 전체 파일 통과를 의미하지 않습니다.
- 데이터 정제 전용 탭 등 후속 기능은 개선 계획이며 이번 버전에 구현된 기능으로 포함하지 않습니다.

이 문서는 변경 내용입니다. 실제 서명·게시 완료는 배포 파일의 서명·타임스탬프·체크섬과 GitHub 릴리스 상태로 확인합니다.
