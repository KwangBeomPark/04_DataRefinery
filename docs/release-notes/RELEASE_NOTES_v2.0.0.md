# Data Refinery v2.0.0 릴리즈 노트

Data Refinery v2.0.0은 기존 Tkinter 기반 데스크톱 UI에서 **현대적인 PySide6(Qt) 프레임워크로 전면 마이그레이션**된 메이저 릴리즈입니다. 특히 컬럼명 수기 입력으로 불편함이 컸던 **'데이터셋 배포(Dataset Publisher)' 탭의 UI/UX를 1,000행 샘플 프로파일러와 3단계 마법사 형태로 대폭 혁신**하였으며, Claude Opus 5.5와 Codex Sol 6.1의 심층 교차 코드 검수를 거쳐 강력한 예외 격리와 성능 안정성을 확보했습니다.

---

## 🌟 주요 변경 사항

### 1. PySide6 (Qt) 모던 데스크톱 UI 전면 마이그레이션
- **완전한 Qt 아키텍처 전환**: 기존 Tkinter의 레거시 스타일을 벗어나 Windows 고해상도(Hi-DPI)에 완벽 대응하는 일관된 모던 디자인 시스템(Primary Blue `#2563EB`, 다크 헤더, 모던 카드, 배지, 스텝퍼)을 적용했습니다.
- **4대 핵심 탭 전면 이식**:
  - **탭 1: CSV 정제/복구 (`CsvRepairTab`)**: 구분자/숫자 모드 자동 감지, 결측치 처리, 엑셀/CSV 변환
  - **탭 2: 프로모션 템플릿 (`PromotionTab`)**: 프로모션 구간별 일자 전개 및 정규화
  - **탭 3: 다차원 집계기 (`AggregatorTab`)**: 그룹 키/수치 열 피커, 비율식 계산기, 고급 필터 모달, 프리셋 저장/불러오기
  - **탭 4: 데이터셋 배포 (`DatasetPublisherTab`)**: DuckDB 기반 누적 검수 및 배포 파이프라인
- **하위 호환성 유지**: 레거시 환경을 위해 `--legacy-tk` 실행 인자를 유지하여 필요 시 기존 Tkinter GUI로도 기동 가능합니다.
- **실시간 다국어 지원**: 한국어(KO), 영어(EN), 폴란드어(PL) 간 즉각적인 언어 전환이 가능합니다.

---

### 2. 4번째 탭('데이터셋 배포') UI/UX 대혁신

기존에는 수많은 컬럼명을 글자 하나 틀리지 않고 직접 타이핑해야 했던 문제를 해결하기 위해 **지능형 3단계 마법사(Wizard)**를 도입했습니다.

- **1단계: 입력 폴더 & 스마트 파일 필터링**
  - 폴더 내 CSV 파일 목록을 즉시 탐색하고, **키워드 칩 필터(`+포함 키워드`, `-제외 키워드`)**를 통해 원하는 파일군(예: `PL`, `sales`)만 손쉽게 선별할 수 있습니다.
  - **체크박스 멀티 선택**: 특정 파일들만 체크하여 선별적으로 DB 누적 대상에 포함할 수 있습니다.
  - **헤더 순서 및 필수 열 사전 검사**: 베이스라인 데이터셋 대비 컬럼 순서(`순서 다름 (이름 기준 정렬)`)나 필수 열 누락(`필수 열 누락`) 여부를 적재 전에 시각적 배지로 표시합니다.
- **2단계: 1,000행 샘플 프로파일러 & Auto-Guess 추천**
  - 파일의 첫 1,000행을 백그라운드에서 읽어 인코딩, 구분자, 데이터 타입을 판별하고 컬럼 역할을 자동 추천합니다:
    - 📅 **기준년월 (Period)**: `기준년월`, `date`, `month` 등 감지 시 자동 배정
    - 🔑 **식별키 (Key)**: `코드`, `ID`, `번호` 등 고유 식별자 복합키 자동 구성
    - 📊 **수치측도 (Numeric)**: `금액`, `수량`, `단가` 등 숫자형 컬럼 자동 분류
    - 🏷️ **일반속성 (General)**: 기타 명칭 및 설명 속성
- **3단계: 복합키 중복 진단 (Collision Detection)**
  - 지정한 복합 식별키를 결합했을 때 1,000행 샘플 내에서 중복 행이 발생하는지 실시간으로 유일성을 진단하고 중복 그룹 수를 경고합니다.

### 3. 유럽식 숫자(폴란드 쉼표 소수점) 왜곡 버그 영구 패치
- 유럽/폴란드 현지 포맷인 쉼표 소수점(`1 234,56` 또는 `12,34`)을 미국식 숫자 처리(쉼표 단순 제거) 시 **숫자가 100배로 튀던 심각한 데이터 왜곡 버그를 발견하고 완전 수정**했습니다.
- `make_numeric_sql_expr` 정규 표현식 기반 안전 캐스팅을 도입하여 점(`.`), 공백(` `), 쉼표(`,`)가 혼재된 유럽형 숫자도 올바른 소수점으로 변환합니다.

### 4. Claude Opus 5.5 & Codex Sol 6.1 심층 교차 검수 반영
- **진행률 콜백 불일치 해결**: 백엔드 엔진의 3인자 콜백 `(pct, msg, detail)` 시그니처 정렬
- **스레드 안전성 강화**: `BackgroundJobRunner.poll` 예외 격리(`try...finally`)로 UI 스레드 타이머 단절 방지
- **엑셀 템플릿 인자 순서 수정**: `create_excel_template_workbook` 파라미터 불일치 수정
- **체크박스 정수형 비교 버그 수정**: `Qt.CheckState` int/enum 비교 호환성 보장
- **스텝 점프 유효성 검사**: 1/2단계 필수 조건 미충족 시 다음 스텝 강제 이동 방지
