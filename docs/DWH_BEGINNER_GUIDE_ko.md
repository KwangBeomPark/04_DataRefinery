## 1. DWH와 손익 마트, 1분 만에 이해하기

### 💡 왜 일반 엑셀 파일 대신 DWH를 만들어야 할까요?
* **엑셀의 104만 행 한계 극복**: ERP 실적 데이터가 수십만~수백만 행으로 늘어나면 엑셀이 멈추거나 파일이 손상됩니다. Data Refinery는 고성능 분석 엔진(**DuckDB**)을 사용하여 1,000,000행도 단 2초 만에 분석합니다.
* **마스터 데이터 무결성 보장 (Fail-Fast)**: 실적 데이터에 아직 등록되지 않은 신규 거래처나 신제품 코드가 섞여 있으면, 숫자가 누락되거나 이익이 왜곡됩니다. Data Refinery는 이를 사전에 감지하여 계산 오류를 원천 차단합니다.
* **자동 워터폴 P&L 손익계산서**: 100여 개가 넘는 복잡한 ERP 비용 계정을 표준 재무 구조(매출액 ➔ 매출원가 ➔ 물류비 ➔ 판촉비 ➔ 공헌이익 ➔ 영업이익)로 자동 롤업 합산합니다.

```
[원천 데이터 (CSV)]
 ├── 고객 마스터 (master_customers.csv)
 ├── 제품 마스터 (master_products.csv)
 └── P&L 실적 (raw_pnl_*.csv)
       │
       ▼ [Data Refinery 1-Click 파이프라인]
 ├── 1. Staging (법인 격리 및 유효성 검사)
 ├── 2. Dimensions (표준 마스터 차원 구축, SCD Type 1)
 ├── 3. Integrity (미등록 코드 Anti-Join 무결성 검증)
 ├── 4. Fact P&L (114개 계정 워터폴 손익 롤업 및 FX 환산)
 └── 5. Serving OBT View (Fan-out 없는 분석용 단일 마트)
       │
       ▼ [초고속 컬럼 저장소 (Parquet)]
[Microsoft Excel Power Query / Power BI / AI 분석]
```

## 2. 사전 준비: 필요한 원천 파일 3종 규격

DWH를 구축하려면 기본적으로 아래 **3가지 CSV 파일**이 준비되어야 합니다. 파일은 프로그램 내 `[폴더 열기]` 버튼을 누르거나 `[📂 파일 가져오기]`를 통해 자동 배치할 수 있습니다.

### ① 고객 마스터 파일 (`data/01_raw/masters/master_customers.csv`)
회사의 모든 거래처(고객사) 목록입니다.
* **필수 컬럼명**:
  * `bill_to_code`: 거래처 고유 코드 (예: `000100200301`)
  * `customer_name`: 거래처명 (예: `MediaExpert Polska`)
  * `channel_group`: 유통 채널 (예: `Retail`, `Online`, `B2B`)
  * `country_code`: 국가 코드 (예: `PL`)
  * `city`: 도시명 (예: `Warszawa`)

### ② 제품 마스터 파일 (`data/01_raw/masters/master_products.csv`)
회사가 취급하는 모든 품목(모델) 목록입니다.
* **필수 컬럼명**:
  * `model_code`: 제품 품번 코드 (예: `OLED65C6P`)
  * `product_name`: 제품명 (예: `OLED TV 65 C6`)
  * `division`: 사업부 구분 (예: `HE`, `HA`)
  * `category`: 제품 카테고리 (예: `OLED TV`, `Washing Machine`)

### ③ P&L 실적 파일 (`data/01_raw/pnl/` 폴더 내 아무 이름의 `.csv`)
ERP에서 내려받은 월별/일별 판매 및 비용 실적 데이터입니다.
* **기본 필수 컬럼**:
  * `period`: 대상 기간 (`YYYY-MM` 형식, 예: `2026-01`)
  * `entity_code`: 법인 코드 (예: `PL`)
  * `bill_to_code`: 거래처 코드 (고객 마스터에 존재하는 코드여야 함)
  * `model_code`: 제품 코드 (제품 마스터에 존재하는 코드여야 함)
  * `currency_code`: 통화 코드 (`PLN`, `EUR` 등)
  * `sales_qty`: 판매 수량 (숫자)
* **손익 계정 컬럼**:
  * `config/account_mapping.yaml`에 정의된 비용/매출 컬럼들 (예: `REV_001`~`REV_010`, `COG_001`~`COG_020`, `LOG_001`~`LOG_015` 등)

## 3. 초보자가 가장 많이 하는 실수 5가지와 방지 팁 (필독!)

| 실수 유형 | 발생하는 현상 | 올바른 작업 팁 |
| :--- | :--- | :--- |
| **1. 엑셀에서 일반 CSV로 저장** | 한글 거래처명이나 제품명이 깨져 물음표(`???`)로 나옴 | 엑셀에서 [다른 이름으로 저장] 시 반드시 파일 형식을 **`CSV UTF-8 (쉼표로 분리)(*.csv)`**로 선택하세요. (일반 CSV는 ANSI/CP949로 저장되어 인코딩 오류가 발생합니다) |
| **2. 코드 앞자리 `0` 잘림** | 거래처코드 `000100`이 숫자 `100`으로 바뀌어 마스터 불일치 에러 발생 | 엑셀에서 파일을 열기 전에 서식을 [텍스트]로 지정하거나, 메모장/VS Code 등 텍스트 에디터로 열어 앞자리 `0`이 온전히 살아있는지 확인하세요. |
| **3. 기간(Period) 포맷 혼용** | `2026.01`, `2026/1`, `202601` 등이 섞여 집계가 누락됨 | 반드시 **`YYYY-MM`** (`2026-01`, `2026-02`) 형식으로 통일하세요. 한 자리 월은 앞에 0을 붙여야 합니다 (`2026-03`). |
| **4. 신규 코드 미등록 실적 등록** | "외래키 무결성 위반 (Fail-Fast)" 에러가 발생하며 빌드 중단 | 실적 파일에 신규 거래처나 신제품이 처음 등장했다면, **반드시 고객 마스터와 제품 마스터 파일에 해당 코드를 먼저 한 줄 추가**한 뒤 빌드해야 합니다. |
| **5. 엑셀로 원천/결과 파일을 열어둔 채 빌드** | `Permission Denied` (권한 거부) 에러 발생 | 엑셀이 CSV나 Parquet 파일을 잡고(File Lock) 있으면 프로그램이 쓸 수 없습니다. 빌드 버튼을 누르기 전 **관련 엑셀 창을 모두 닫아주세요.** |

## 4. 단계별 실행 가이드 (1단계 ~ 3단계)

### [1단계] 원천 데이터 및 설정 확인
1. Data Refinery를 실행하면 첫 화면으로 **`1. 🏛️ 손익 마트 생성 (DWH)`** 탭이 열립니다.
2. 만약 아직 테스트 중이라면 **`[✨ 샘플 원천 데이터 자동 생성]`**을 눌러보세요. 실제 폴란드 법인의 마스터와 100+ 컬럼 P&L 실적이 즉시 생성됩니다.
3. 본인의 실제 데이터를 넣으려면:
   - 방법 A: **`[📂 파일 가져오기]`** 버튼을 눌러 내 PC의 CSV를 선택하면 올바른 폴더로 자동 복사됩니다.
   - 방법 B: **`[폴더 열기]`**를 눌러 열리는 탐색기 창의 `masters/`와 `pnl/` 폴더에 CSV 파일을 직접 복사해 넣습니다.
4. 상태 표시줄에서 모든 항목이 녹색 체크(`✔`)로 바뀌었는지 확인합니다.

### [2단계] DWH 빌드 및 무결성 검증 (1-Click)
1. 세 파일이 모두 준비되면 비활성화되어 있던 **`[★ 1-Click DWH 파이프라인 전체 빌드]`** 버튼이 파란색으로 활성화됩니다.
2. 버튼을 클릭하면 백그라운드에서 5단계 엔진이 자동으로 동작합니다:
   - `1. Staging 추출`: 대상 법인(PL) 데이터만 초고속 추출
   - `2. Dimensions 빌드`: 고객, 제품, 일자 마스터 차원 생성
   - `3. FK 무결성 검증`: 실적 데이터의 모든 코드가 마스터에 존재하는지 정밀 대조
   - `4. Fact P&L 손익 롤업`: 114개 계정을 합산하고 환율을 곱해 원화/PLN 및 현지통화 워터폴 계산
   - `5. OBT 뷰 및 Parquet 발행`: 엑셀 파워쿼리용 통합 마트 파일 생성
3. 정상 완료되면 매출액과 영업이익 총액 요약과 함께 성공 팝업이 뜹니다.

### [3단계] 결과 확인 및 엑셀 연동
1. **[📊 마트 데이터 즉시 미리보기]** 버튼을 누르면 엑셀을 켜지 않고도 결과 상위 50행을 화면에서 즉시 확인할 수 있습니다!
2. **[⚡ Power Query M-코드 복사]** 버튼을 누르고 엑셀 파워쿼리 고급 편집기에 붙여넣으면 피벗 테이블이 단 1초 만에 완성됩니다.

## 5. Microsoft Excel 파워쿼리 1초 직결법

### 방법 A. M-Code 1초 직결법 (가장 빠르고 확실함)
1. 카드 3에서 **`[⚡ Power Query M-코드 복사]`** 버튼을 클릭합니다.
2. **Microsoft Excel**을 실행하고 새 통합 문서를 엽니다.
3. 상단 메뉴에서 **[데이터] ➔ [데이터 가져오기] ➔ [기타 원본에서] ➔ [빈 쿼리]**를 클릭합니다.
4. 파워 쿼리 편집기 창이 뜨면 상단의 **[고급 편집기]** 버튼을 클릭합니다.
5. 기존 내용을 모두 지우고 클립보드 내용을 붙여넣기(`Ctrl + V`)합니다:
   ```powerquery
   let
       Source = Parquet.Document(File.Contents("C:\Users\...\v_ai_pnl_summary.parquet")),
       #"Navigated" = Source
   in
       #"Navigated"
   ```
6. **[완료]**를 누른 뒤 좌측 상단의 **[닫기 및 다음으로 로드...] ➔ [피벗 테이블 보고서]**를 선택합니다.
7. 이제 엑셀 피벗 테이블에서 `period`(행), `channel_group`(열), `gross_revenue_reporting`(값), `operating_profit_reporting`(값) 등을 드래그하여 자유자재로 손익 분석을 수행할 수 있습니다!

## 6. 에러 발생 시 자가 해결(Troubleshooting) 매뉴얼

### 🚨 상황 1: "외래키 무결성 위반 (미등록 마스터 코드 발견)"
* **원인**: 실적 데이터(`pnl`)에는 코드가 적혀 있는데, 마스터 파일(`master_customers.csv` 또는 `master_products.csv`)에는 그 코드가 누락된 상태입니다.
* **해결법**: 에러 박스 상단에 표시된 **`누락 코드 힌트`**를 확인하고, **`[📝 마스터 폴더 열기 (코드 추가)]`** 버튼을 눌러 마스터 파일 맨 아래 줄에 해당 코드를 추가한 뒤 다시 빌드하세요.

### 🚨 상황 2: "Permission Denied: ... v_ai_pnl_summary.parquet"
* **원인**: 엑셀에서 해당 CSV나 Parquet 파일을 이미 열고 있는 상태입니다.
* **해결법**: 열려 있는 엑셀 창을 모두 닫고 다시 [빌드] 버튼을 누르세요.
